# Critical stack package policy for smplOS updates.
# These are the ONLY packages excluded from regular `pacman -Syu` passes;
# everything else (kernels, microcode, bootloader, mesa, nvidia stack,
# hyprpaper/hypridle/hyprlock, xf86-video-*, xdg-desktop-portal, etc.)
# updates naturally against Arch upstream.
#
# Rationale: freezing packages is a security/stability cost (missed CVE
# fixes, long-tail divergence from Arch) that only pays off for packages
# whose ABI is locked across the wider smplOS stack. In practice that is
# just Hyprland and its Wayland portal — Hyprland plugins are ABI-locked
# to the exact compositor build, and xdg-desktop-portal-hyprland tracks
# that same API. Everything else can (and should) roll forward with Arch.
#
# When we need a new coordinated Hyprland version fleet-wide, bump the
# BUNDLE_ID + pin in critical-bundle.conf and smplos-update will apply
# the whole set as one atomic step (with prompt + reboot).
#
# Keep one package per line. No commas.

hyprland
xdg-desktop-portal-hyprland
